# Praxis Design System

The Praxis visual language is shared between the handcrafted shell and the apps generated by the BUILDER agent. Generated HTML MUST use these classes for common controls so output stays visually coherent with the OS.

## Tokens (Tailwind)

- **Backgrounds**: `bg-praxis-navy` (desktop), `bg-praxis-navy2`, `bg-praxis-surface`, `bg-praxis-surface2`
- **Borders/edges**: `border-praxis-edge`
- **Brand gradient**: `bg-tech-magic` (cyan → violet)
- **Accent colors**: `text-praxis-cyan`, `text-praxis-violet`
- **Text**: `text-praxis-text` (primary), `text-praxis-muted` (secondary)
- **Fonts**: `font-display` (Space Grotesk, headings/brand), `font-sans` (Inter, body), `font-mono` (JetBrains Mono)
- **Glow shadows**: `shadow-glow` (cyan), `shadow-glow-violet`, `shadow-window`

## Shared classes

| Class | Use for | Notes |
| --- | --- | --- |
| `.praxis-display` | Headings / brand text | Display font + subtle glow |
| `.praxis-card` | Surfaces, panels, windows | Rounded, bordered, blurred surface |
| `.praxis-input` | Text fields, search | Full-width, focus glow |
| `.praxis-btn` | Base button | Compose with variants below |
| `.praxis-btn-primary` | Primary action | Tech-magic gradient |
| `.praxis-btn-ghost` | Secondary action | Surface + edge border |
| `.praxis-chip` | Tags, status | Small pill |
| `.praxis-divider` | Section separators | Gradient hairline |
| `.praxis-streaming` | In-progress generation shimmer | Animated cyan sweep |

## BUILDER contract

When the BUILDER emits controls (buttons, cards, inputs, display surfaces) it MUST apply the matching `.praxis-*` classes where semantically appropriate. Local CSS extension inside a generated app is allowed, but common controls should reuse the shared classes.

For generated apps rendered inside `iframe srcdoc`, the BUILDER should inline a minimal copy of these class definitions (or link to a Praxis CSS string provided in the prompt context) so the iframe remains self-contained.

## Tone

Dark navy, tech-magic: cyan-to-violet gradients, soft glows, restrained surfaces. Keep generated UIs minimal, legible, and consistent with the shell.
